# Segment-Display

This repository contains display products and Arduino UNO R3 demo sketches.

## Products

### Ten Segment LED Bar Display Kit

- Docs: `Ten Segment LED Bar Display/README.md`
- Arduino UNO R3 sketch: `Ten Segment LED Bar Display/codes/Uno_10SEG.ino`

### 0.56 Seven Segment LED Display Kit

- Docs: `0.56 Seven Segment LED Display/README.md`
- Arduino UNO R3 sketch: `0.56 Seven Segment LED Display/codes/Uno_056SEG.ino`

### 0.28 Eight-Digit SEG Display

- Docs: `0.28 SEG Display/README.md`
- Arduino UNO R3 sketch: `0.28 SEG Display/codes/Uno_0288SEG.ino` (requires **LedControl** library; **MAX7219** **DIN / CLK / CS**)

### 4.7 SEG Display

- Docs: `4.7 SEG Display/README.md`
- Arduino UNO R3 sketch: `4.7 SEG Display/codes/Uno_47SEG.ino` (set `NUM_DIGITS` for one module or a cascade chain)
